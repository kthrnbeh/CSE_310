# Overview

This program is a simple "Hello, World!" program that displays text in the terminal using the Python programming language.

This software shows how simple it can be to write a quick program in Python. It took me less than a minute to write, and it works. Something simple like this can create motivation for others who feel overwhelmed by the complexities of coding. When you can easily accomplish one thing at the beginning, it makes the next steps feel like they can be achieved.
